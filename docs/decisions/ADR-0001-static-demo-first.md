# ADR-0001：先交付静态 Demo，再扩展后端闭环

- 状态：Accepted
- 日期：2026-10-17

## 背景

项目的首要展示价值是无需注册、无需密钥即可查看 trace、回放和故障策略对比。后端、数据库和真实 Agent 执行会显著增加部署、安全和外部权限门槛。

## 决策

P0 采用 React/Vite 静态 Demo，所有展示数据为版本化、脱敏、确定性的 fixture；页面通过 `TraceDataSource` 抽象访问数据。P1 再实现 FastAPI、数据库和受控 adapter，保持相同领域契约。

## 结果

- 优点：快速形成可验证垂直切片；可在 GitHub Pages 无密钥发布；没有任意工具执行风险。
- 代价：P0 不提供真实持久化和真实 Agent 重启；必须在 UI 中明确标注 replay/mock 语义。
- 迁移策略：先固定 schema/API 文档和 fixture，API adapter 实现接口后替换数据源，不重写页面状态模型。

## 安全影响

导入和 fixture 只当作数据，禁止执行。任何真实后端部署必须追加认证、限流、脱敏、审计和授权审查。
